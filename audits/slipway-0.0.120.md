## Remaining boundaries

- Automatic PR preview lifecycle, GitHub CI status mirroring, remote runner scheduling, extra CI service profiles and shared caches are not delivered by this release. Documentation must not imply otherwise.
- Bosun omits analytics.db from its overview and SQL selector. This documentation change explains the boundary; it does not silently add an unreviewed SQL capability.
- Resident Quest runtime compatibility depends on separately published app dependencies and explicit app configuration. Verified npm versions on 24 October 2026: Quest 0.0.8 and Slipway hook 0.0.13.
- CI screenshots are from a real isolated localhost Sailsconf source pilot, not a production installation. Production owner approval follows manual server/CLI installation.
- Full installation, npm publication, browser production checks and disaster recovery are separate from docs build verification. Link checks cannot establish those outcomes.

## Verification

Run `SLIPWAY_CLI_SOURCE=/path/to/slipway/packages/cli npm run check:slipway-docs`, `npm run lint`, `npm run build`, then `npm run check:slipway-build`. The fixture records the reviewed release source; the public Updates guide records publication status independently. A scoped GitHub workflow repeats the immutable-source command check, docs build and rendered-link checks on future Slipway documentation changes.
