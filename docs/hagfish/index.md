Hagfish brings invoices, clients, and expenses into one workspace. Use the web app to manage your business, or bring invoicing into your own workflow with the API and CLI.

## From a draft to a delivery

Create the client, draft the invoice, and review the total and applicable credits before exporting a PDF or requesting a send. Hagfish uses your existing plan and credits.

[Explore the API →](/hagfish/api/) · [Use the CLI →](/hagfish/cli/)
